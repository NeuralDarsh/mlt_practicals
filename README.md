## 📖 About

This repository is a collection of practical assignments for the **Machine Learning Techniques (MLT)** course in the B.Tech (AI & ML) program at **D.Y. Patil Agricultural and Technical University, Talsande**.

Each notebook covers one concept end to end: loading data, preprocessing, training a model, evaluating it, and visualizing the results.

## 🚀 Getting Started

### Option 1: Run on Google Colab (no setup needed)
Click any **Open in Colab** badge in the [Practicals](#-practicals) table, then run the notebook with `Runtime → Run all`.

### Option 2: Run locally

```bash
# 1. Clone the repository
git clone https://github.com/NeuralDarsh/mlt_practicals.git
cd mlt_practicals

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch Jupyter
jupyter notebook
```
